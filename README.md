# BST_Conteneur

Module Odoo 19 pour gérer la référence du conteneur sur les devis et commandes de vente.

## Fonctionnalités

- Champ Conteneur sur `sale.order`
- Saisie exclusivement via un assistant
- Confirmation bloquée si le conteneur est absent
- Modification possible après confirmation via le même assistant
- Chatter grâce au suivi du champ
- Liste, kanban et recherche
- Group By Conteneur
- Impression conditionnelle sur le PDF
- Tests automatisés

## Installation

Copier `BST_Conteneur` dans le addons path Odoo, mettre à jour la liste des applications puis installer le module.

Le code est en anglais et les commentaires sont en français.
